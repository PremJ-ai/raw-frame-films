========================================
PROJECT OVERVIEW
========================================
A cinematic production company website built with React 19, Vite 8, TypeScript, and Framer Motion.
Features a 3D hero section with scroll-triggered camera animation and a 3D service carousel.

========================================
KEY COMPONENTS
========================================

1. HeroSection.tsx (src/components/HeroSection.tsx)
   - 3D camera model built with CSS transforms
   - Scroll-triggered animations via Framer Motion useScroll/useTransform
   - Camera rotates X/Y, translates Y, scales on scroll
   - Navigation: Home, Services, Team, Contact (smooth scroll)
   - Animated headline, subheadline, stats counters
   - Contact section with form + contact details
   - Floating particles, focus lines, lens ring animation

2. ServiceCarousel.tsx (src/components/ServiceCarousel.tsx)
   - 5-service horizontal carousel with 3D depth
   - CSS 3D transforms: translateX, translateZ, rotateY, scale
   - Keyboard (arrows), wheel, touch navigation
   - Auto-play disabled, pause on hover
   - Video backgrounds from Mixkit CDN
   - Active card highlighted, side cards dimmed

3. CameraScene.tsx (src/components/scenes/CameraScene.tsx)
   - Three.js scene with camera model
   - Scroll-controlled camera movement

4. ScrollVideoScene.tsx (src/components/ScrollVideoScene.tsx)
   - Video scrubbing tied to scroll position

5. useScrollScrub.ts (src/hooks/useScrollScrub.ts)
   - Custom hook for scroll-based video scrubbing
